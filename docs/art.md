# 美术与界面

这份文档是美术和界面这条线的起点：定了什么、受什么约束、要做多少东西、还有什么没定。
规则和数值不在这里，见 `docs/rules.md` 和 `docs/numbers.md`。

## 一、定了的方向

- **不照参考作的画面。** 规则和数值对齐参考作（`AGENTS.md` 规则 2、15），长相是自己的：
  对话框、菜单、战斗布局、图标、字体全部重做，不描它的样子。
- **画风就是《八方旅人》**（开发者定的规矩，`AGENTS.md` 规则 17）：画面上的事「该怎么画」，照《八方旅人》怎么做来回答，
  不重新拿来讨论；只学画风，不拿它的任何东西（人物、图、界面、文字，规则 3）。做不到的列在第八节，逐条补。
- **HD-2D：像素人物站在 3D 小景里**（原先的体素风改成这条）。
  人物和异兽是平面的像素图（sprite），竖着立在 3D 的地图上，有四个朝向和走路的帧；地面和墙是 3D 的，
  贴像素颗粒；画面上再加一层「镜头」：远处和近处模糊、中间清楚（移轴），四角压暗。选它的理由：
  1. 量大也做得动。一只异兽是一张几十像素见方的图，比体素模型省；风格天然统一。
  2. 地形、植被、水面仍可以由代码生成。
  3. 像素是风格的一部分，镜头效果让小景有景深，不显得粗糙。
  体素那一套（`Voxels`、`art/beasts`）已经全部换掉、删了。
- **自己的味道。** 配色往青绿山水靠（石青、石绿、赭石），界面多留白，字有书法感；
  要一眼看得出是山海经，而不是通用的体素游戏。
- **信息结构沿用熟悉的。** 战斗里四个招式、体力条、队伍六只、背包分类，玩家上手快；只换视觉。
- **像素图写成数据，不用外部工具。** `art/sprites/` 下一个一个 PHP 文件（`people/` 人物、`things/` 地图上立着的东西、
  `ground/` 地面纹理），一行一串字符、一个字符一个像素，格式写在 `src/Render/Sprites.php` 的类注释里。
  可以手写（人物、告示牌），也可以在文件里用代码画（树冠、石头按光从左上来的球体分几档明暗、档与档之间用 4×4 Bayer 网点过渡，
  `Sprites::blob`；草叶、地面的散点用 `Sprites::noise`，每次一样）。描边由代码画，不手写；朝右是朝左翻过来。一格 32 像素，
  人物 24×44。
- **建筑的比例照《八方旅人》**：人画面上约 1.4 格高，头占四分之一（不是大头娃娃）。室外的墙都是房子：
  夯土抹灰、深色木框，墙高 2.4 格，门比人高一个头，茅草屋顶的屋脊再高 1.6 格、屋檐伸出 0.3 格，
  整栋到屋脊约人的三倍高（`Stage::HOUSE_TOP`、`RIDGE`、`EAVES`，`Stage::roof()`）。
  室内的墙 2.2 格；挡在镜头和地板之间的那面墙（墙的北边是地板）切到 0.3 格高，和它一样把近处的墙切掉，屋里才看得见。
  木地板一块板宽四分之一格，约人肩宽的三分之一。
- **东西的比例照《八方旅人》**：树比人高得多（64×96，两格宽三格高，树冠罩到旁边的格子），石头只到膝盖（32×18），
  深草挡到膝盖（32×16）；不是每样东西都一格大小。树按位置左右错开一点，一片树林才不像棋盘。
- **画面里没有世界的尽头**：室外的地图四周多画一圈地（`Stage::BEYOND`，上 20、下 10、左右各 16 格）：
  有出口的那边画的是隔壁的地图，原样（`World::neighbours`），走过去不淡出、不黑屏，地接着走下去，照参考作的路和城镇连着
  （规则 2：这是玩法；它自己的区域之间是淡出切换，不照它）。进门、进洞、读档照旧淡出。
  换图时用隔壁的场景，建好的留着（`Play::STAGES` 张），来回走不再重建；第一次走过去要建一次，可能顿一下。
  隔壁地图上的人不画，走过去才出现。隔壁之外、没有出口的边、隔壁比这边短的地方，画开阔的草地，零星几棵树、几块石头、几丛深草（`Stage::WILD`），
  不是一堵树墙（开发者看了说树太多，它的场景很协调）。室内四周是黑的，和它一样。
- **人物要圆，不能像纸片**：它的人物也是平面像素图，看起来圆，是因为画的时候就有体积的明暗：一侧亮、一侧暗，
  头和身子像圆柱、圆球。我们的人物先用代码补上（`Sprites::round`，像素图里写 `'round' => true`）：每行的一段像素当成圆的截面，
  光从左前方来，分五档明暗、档间网点过渡。之后人物重画时直接按这个画，画得更细。
- **挡住主角的东西变成网点**：站在主角前面（靠镜头）、高到能挡住主角大半身的东西（树、房子），
  隔一个像素去掉一个，透出后面的主角（`Stage::fades`、`Stage::hides`、`Sprites::fade`）；深草和石头矮，不变。镜头斜着看，直立的图在画面上会变矮，所以立起来时按镜头的斜度拉高（`Stage::stretch()`），画面上和写的一样高。
- **异兽是侧面的像素图**（`art/sprites/beasts/`），朝左画，朝右翻过来；照 `looks` 原文逐只画，
  文件里带上这段原文，测试核对它和 `data/beasts.php` 一字不差。鹿蜀 64×48（两格宽、一格半高）。
  还没画的用占位图（`beasts/placeholder`，一团圆圆的小兽），按第一属性上色。
  画法：身体、头、四肢都是代码画的团块（`Sprites::blob`、`limb`），花纹用 `pattern`，眼睛、喙这类小处用 `dots`。
- **画面的颗粒**：每格地面按位置略亮或略暗（`Stage::shade`，正负 5%），同一位置每次一样。
- **地面按材质贴像素纹理**（`art/sprites/ground/`，一格一张 32×32，能无缝平铺）：草、土路、碎石、沙、木地板、门槛、水、墙砖。
  每格按位置左右或上下翻转（不旋转，木板、砖缝、水纹的走向才一致），看不出重复；墙的侧面按高度往下平铺。
- **镜头**（`Play::lens()`）：上方一半往上越来越糊，下方 28% 往下越来越糊（远处糊得多），四角压得比较暗（照它的截图调过）；
  用的是框架的背景模糊（`Painter::blurLevel`）和径向渐变。泛光（bloom）框架没有，暂不做。

## 二、不能动的约束

这些来自 `docs/rules.md` 和 `AGENTS.md`，美术不改它们，只在它们里面做：

- **固定俯视**：相机以固定俯角跟随主角，不旋转、不缩放（现在是高 10、后退 15、视场角 32 度，约俯 34 度，
  `Stage::CAMERA_*`；改 HD-2D 时从高 8、后退 6.5、40 度放低，像素人物要从偏正面看；拉远到画面纵向约 10 格，
  人物约占画面高的八分之一，和参考作、《八方旅人》差不多，近了人物显得比场景大）。模型只需要从这个角度好看。
- **画面比例跟着窗口**：3D 画面高 720 像素，宽按窗口的比例算（`Play::VIEW_HEIGHT`），像素始终是方的；
  窗口初始 1280×720（16:9）。4:3 不是参考作的规矩，不必守。
- **格子地图**：一格一个单位，四个方向，一步一格。地形可以起伏、可以有梯田和海岸，
  但能不能走、哪里遇敌仍由图块决定。
- **规则不画，画不定规则**（规则 12）：`src/World`、`src/Battle`、`data/` 里不出现任何绘制的东西；
  美术只动 `src/Render`、`src/Play.php` 和资源文件。
- **先用框架自己的**（规则 13）：`Plugins\Scene` 的 `Animator3D`、`ParticleEmitter3D`、
  `Mesh::terrain`、`sceneFromGlbFile`、`Material::pbr`/`unlit`、`ScreenTransition` 等，缺的在框架里补，先问。
- **内容只取自《山海经》或原创**（规则 3）：不用别的游戏的角色、图、文字。
  异兽的造型照 `data/beasts.php` 里 `looks` 写的原文来，不凭印象（规则 4）。
- **字要画得出来**（规则 16）：界面上的字必须是所用字体里有的；换字体时这条测试要跟着过。
- 不加第三方包，先问（规则 5）。

## 三、现在是什么样

改走 HD-2D，第一步做了人物和镜头，等实机画面确认：

- **地图**（`src/Render/Stage.php`）：地面按图块的纹理分成几张网格，墙一张，每格略有明暗。
  树、深草、石头、告示牌是 `art/sprites/things/` 的像素图，竖着立，各一次实例化绘制，脚下有网点影子；
  深草立在格子中间稍靠前，走进去的人下半身被挡住；别的稍靠后，站在旁边的人不会和伸过来的树冠打架。
  人物都是像素图 `art/sprites/person`（三个朝向，各有站立和走路两步），袍子按身份上色（`Stage::LOOKS`），
  脚下一块网点的影子（场景不支持半透明，用隔一个点画一个的网点代替）。

- **战斗**（`src/Render/Arena.php`）：照地图的画法，一片草地（`Arena::FIELD`，后面几排树、两边石头、几丛深草），
  我方异兽在左前、朝右，对方在右后、朝左，侧面像素图立着、不受光、脚下网点影子；镜头固定，同样的移轴和压角。
  呼吸、扑击、受击的动作是整张图的位移和缩放（`Animator3D`）。布局（谁在哪）照参考作，画法照它。
  现在只有鹿蜀有自己的图，其余是占位图。
- **界面**照它的路数、用自己的纹饰。所有画界面的东西都在 `src/Render/Ui.php` 一处（开发者要求：以后调整只改这里），
  `Play` 只决定哪一屏显示什么，自己不画界面（测试会检查）；列表旁边说明框里的字由 `src/Info.php` 写（可测）。
  所有框都是同一种面板（`Ui::panel`）——深色、略透、往下更暗，
  一圈金线、里面一圈暗金细线、四角各一颗菱形；字用衬线（系统有宋体就用宋体，`Play::SERIF`），米白色，数字和注释小一号、金色。
  选中的一项：前面一颗菱形，背后一条从左往右淡去的金色光带，没选中的字暗一些。对话框右下角的「继续」是一颗上下轻晃的菱形。
  地图名：走进一张图时在画面顶部居中出现，两边金线往外淡去，停 3.5 秒后淡出（`Play::NAME_SECONDS`）。
  标题画面的游戏名同样夹在两条金线之间。战斗的状态框：名字、金色等级、细血条（渐变的绿 / 琥珀 / 红）、经验条。
  列表按最长的一项自动加宽（`Ui::list`），`docs/issues.md` 第八节那批「放不放得下」的问题由此解决。
  列表旁边的说明框（`Ui::info`）：战斗里选招式时，招式的属性、威力、命中、次数和出处；背包、携带、商店里，东西的用处和出处（商店带价钱）；
  图鉴里，见过的异兽的像素图、名字、种类和出没的山。凡是列队伍的地方（异兽、详情、用药、战斗里换人和用药），
  都画成一行一只：名字、等级、状态、血量数字和血条（`Ui::party`）。
  详情是一页（`Ui::sheet`）：左边异兽的像素图，右边名字、等级、属性、血条、能力、经验和携带、招式、天分和亲近，上下键翻看队伍里的下一只。

## 五、哪些能由代码生成，哪些要有人做

- **代码生成**：地形起伏、梯田、海岸、水面、草和树的摆放、简单的房屋和围栏、天空、粒子。
  450 张图不可能一张张手摆，这部分必须程序化，按山系给参数（地面颜色、植被、有没有水）。
- **要有人或工具做**：异兽、神、人物。这些有造型，要照原文的描述来。
- **代码这边负责接进来**：模型格式和加载、朝向、待机和行走的动作、战斗里的出招和受击、图标图集。

## 八、和《八方旅人》还差什么

现在对上的是骨架：像素人物立在 3D 地图上、固定的斜俯镜头、移轴模糊、四角压暗、人物在画面上的大小。
下面是还没对上的，按「我们自己能做」和「要框架先补」分开（框架缺的照规则 13，先问再在 myphp 里补）。

我们自己能做：

1. ~~战斗里的鹿蜀换成像素图~~：换了，战斗场景也照地图的画法重做了。
2. **地面纹理的过渡**：每种地面有了自己的纹理，但图块交界是硬边；它的交界处有过渡（草边、路缘）。
3. **人物更细、更活**：站着有呼吸的待机帧，走路帧更多，转身、说话有小动作。
4. **地形有高低**：台阶、坡、崖、梯田（第五节的程序化生成）。
5. ~~界面~~：对话框、菜单、战斗的框、说明框、队伍的行照它的路数重做了（第三节）。还差：图标。
6. **粒子**：飞尘、萤火、落叶、水花，用框架的 `ParticleEmitter3D`。

要框架先补：

1. **泛光（bloom）和调色**：亮处向外晕开、整体偏暖的色调。现在没有。
2. **按深度的景深**：它的模糊按离镜头的远近；我们是按画面上下的条带，近处高的东西（树冠）不会糊。要拿到深度缓冲。
3. **光照在像素人物上**：灯笼、火把这类点光源照亮人物和地面；现在人物不受光（`Material::unlit`）。
4. **半透明**：柔和的影子、雾、光柱、水面的透明和反光；场景现在只有「全透明或不透明」，所以影子用的是网点。
