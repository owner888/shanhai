# 路线图

顺序即依赖：后一项要用到前一项的结果。每一项写明「完成标准」，达到才算完。

已定的事：
- 不做进化。
- v0.1 的图鉴开放《南山经》全篇（先全再细）。
- 属性表在图鉴总表之后定，由全书异兽的实际分布决定种数。
- 参考作里的已知缺陷按本意实现，不照搬（`docs/numbers.md` 第 9 节）。
- 神是两层首领，不能收服：每列山系一位守山神，其上是四方之神。
- 不设「特性」系统；书里的征兆和功效落到天气、道具和招式上。
- 初始三只在第 3 档，六项之和相同。
