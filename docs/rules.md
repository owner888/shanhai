# 游戏规则

v1 一律照此执行；出一个版本之后再考虑调整。

## 玩法与呈现：照经典掌机怪物收集 RPG 的做法

- **视角**：固定俯视。相机以固定俯角跟随主角，不旋转、不缩放。
- **移动**：格子地图，四个方向，一步一格。轻点转向，按住行走。
- **地图**：由图块、碰撞、传送点、NPC、告示牌、触发器组成；站在门上进屋，走出门回到外面。
- **事件**：对话、给物品、设标志位、移动角色、传送，全部由事件脚本驱动；脚本运行时玩家不能操作。
- **遇敌**：在深草里行走随机遇到野生异兽。（M3）
- **战斗**：一对一回合制，每只异兽四个招式，队伍最多六只，等级上限一百。（M2）
- **成长**：六项能力值（体力、攻击、防御、特攻、特防、速度），加个体差异与培养值。（M2/M3）
- **伤害**：由等级、招式威力、攻防之比、属性倍率、随机浮动、要害共同决定。（M2）

## 内容：全部取自《山海经》或原创

- **异兽**：出自《山海经》。名字、所在的山、形貌、功效按原文写，逐条核对，不凭记忆。
- **地图**：按原文的山系排布。v1 是《南山经》之首，从招摇之山到青丘之山。
- **属性、数值、招式、对白、剧情**：原创。
- 不使用任何其他游戏的名字、角色、地图、文本或数值表。

## 九种属性

| 属性 | 克制 |
|---|---|
| 焰 | 木、霜 |
| 潮 | 焰、岩 |
| 木 | 潮、岩 |
| 岩 | 焰、雷 |
| 风 | 木、影 |
| 雷 | 潮、风 |
| 霜 | 风、木 |
| 影 | 雷、辉 |
| 辉 | 影、霜 |

以 `data/elements.php` 为准。

## 初始三选一

鹿蜀（焰）、旋龟（潮）、灌灌（木）：焰克木，木克潮，潮克焰。
